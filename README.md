# TravelTrucks

A web application for browsing and booking campers. Built with Next.js,
TypeScript, and TanStack Query.

## 🔗 Live Demo

https://travel-trucks-eta-livid.vercel.app/

## 📦 Repository

https://github.com/dianapri0303/travel-trucks

---

## ✨ Features

- Camper catalog with filters (location, form, engine, transmission)
- Pagination with “Load More”
- Camper details page with gallery and reviews
- Booking form with API integration
- Success toast notification
- Responsive UI based on Figma design
- Loading states (spinners)

---

## 🛠 Tech Stack

- Next.js (App Router)
- TypeScript
- TanStack Query
- CSS Modules
- React Hot Toast
- Swiper

---

## 🚀 Getting Started

```bash
git clone https://github.com/dianapri0303/travel-trucks.git
cd travel-trucks
npm install
npm run dev
```

Open http://localhost:3000
